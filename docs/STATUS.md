## Important limits

- The prototype uses SQLite SQL contracts, not full application processes or a real rolling deployment.
- No concurrent transactions, lock contention, mid-statement interruption, final contract-phase execution, or PostgreSQL/MySQL coverage.
- The public HTTP service has request-size/origin checks and bounded candidate execution, but it is a hackathon demo without verified multi-tenant resource isolation. Imported SQL is sent to the demo host and held only for the request, so private schemas belong on a local instance. Render's free service can spin down after inactivity and take around a minute to wake.
- A passing reference plan is not proof of Bob authorship. Bob Shell completed only pre-event readiness checks; no qualifying event-period Bob repair or product extension has been run.
- Browser download-event instrumentation timed out, but the browser-created JSON file was found on disk and its content was verified. Visual checks used Brave earlier and the in-app browser during the September 23 public retest.
- CI passed on Ubuntu and Windows; macOS was not tested. No submission has been made. The project submission page currently says it is available only during the active phase.
