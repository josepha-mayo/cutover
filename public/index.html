Coverage, constraints & Bob integration status ↗
This prototype executes 19 completed-rollout schedules for each input string, plus old updates and inserts at every boundary between SQLite migration statements. Two bundled contracts use four strings each; an imported, validated single-table SQLite contract can supply 2–8. It does not simulate concurrent transactions, database locks, network failures, mid-statement interruption, or a final column removal.
Imported SQL runs in a bounded disposable worker on this hosted demo and is not persisted by the application. The hosting service receives the request; run private schemas locally. IBM Bob integration is prepared through a local MCP server for the bundled samples. No Bob session has been verified yet. The reference plans are prewritten examples; selecting one does not invoke an AI model.
