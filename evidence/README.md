# Reproducible sample evidence

`summary.json` and the eight `{case}-{candidate}.json` files were generated by engine v0.3.5 from the checked-in contracts and four primary reference plans. The checked-in reports retain the exact plan, contract/suite/engine hashes, the shortest observed failure and one passing migration-window replay. They omit the repetitive full probe array so the repository remains reviewable. The separate cross-record negative control is available in the live demo and fixture files; it is excluded from the original three-pattern ablation. The application exports the complete report; regenerate these compact reports with `python -m evidence.build_reports`. Regeneration updates observed timestamps and durations.

`v0.1-browser-export-trigger-removed.json` is retained locally as historical negative-control evidence and excluded from the public repository. It used engine v0.1.0, before migration-window probes existed, and must not be compared numerically with v0.3.5 reports. No file here is evidence of a real IBM Bob host session.
