# Reproducible sample evidence

`summary.json` and the eight `{case}-{candidate}.json` files were generated by engine v0.2.0 from the checked-in contracts and reference plans. The checked-in reports retain the exact plan, contract/suite/engine hashes, the shortest observed failure and one passing migration-window replay. They omit the repetitive full probe array so the repository remains reviewable. The application exports the complete report; regenerate it by running `rehearse(case, load_plan(case, candidate))` for both cases and all four candidates.

`v0.1-browser-export-trigger-removed.json` is retained locally as historical negative-control evidence and excluded from the public repository. It used engine v0.1.0, before migration-window probes existed, and must not be compared numerically with v0.2.0 reports. No file here is evidence of a real IBM Bob host session.
